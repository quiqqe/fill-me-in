# fill-me-in

Плагин для Claude Code: ответы агента понятны человеку, который не видел, как агент работал.

## Зачем

Агент держит в голове весь процесс: какие файлы читал, какие гипотезы отбросил, как что называл
по ходу. Итоговый ответ он пишет так, будто вы были рядом. Термины знакомы, а смысл ускользает:
связи между ними остались в той части работы, которую вы не видели.

## Что внутри

- **Правило на каждый ответ.** Хук при старте сессии (а также после `/clear` и сжатия контекста)
  подставляет агенту правило: сначала ситуация, потом вывод; к каждому выводу «что, почему,
  что делать»; не ссылаться на то, что видел только он. Уровень объяснений подбирается по теме
  и по признакам из диалога: спрашиваете, что значит термин, — объясняет подробнее; говорите
  на языке специалиста — не разжёвывает.
- **Команда `/fill-me-in`.** Если ответ всё же вышел непонятным: агент находит, на какой
  невидимый вам контекст опирался, перепроверяет факты и перерассказывает. Сначала суть одной
  фразой, потом как устроен механизм, пример по шагам и что из этого следует.
  `/fill-me-in <место>` объясняет только названное место.

## Совместимость с сокращающими плагинами

Если у вас стоят плагины, которые сжимают вывод (ponytail, caveman и подобные), fill-me-in
приоритетнее в объяснениях: они пусть режут код и повторы, но не контекст и причины. Правило
подставляется на старте сессии, а короткое напоминание добавляется к каждому вашему сообщению,
чтобы оно не терялось на фоне других инструкций. Прямая просьба в сообщении («только код»)
по-прежнему выполняется.

## Установка

```
/plugin marketplace add quiqqe/fill-me-in
/plugin install fill-me-in@fill-me-in
```

Только skill, без правила, для других агентов:

```
npx skills add quiqqe/fill-me-in
```

**English.** A Claude Code plugin that makes agent answers understandable to someone who did not
watch the agent work. A SessionStart hook injects a writing rule (situation first, then the
conclusion; what, why, and what to do; explain mechanisms when the dialogue shows the topic is
unfamiliar). The `/fill-me-in` command re-explains an unclear answer: the missing context first,
then the mechanism, a step-by-step example, and what it means. The texts are in Russian.
